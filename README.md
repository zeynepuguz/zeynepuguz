## 🔬 Featured Projects

### 🎓 [UniGuideAI — AI-Powered University Recommendation System](https://github.com/zeynepuguz/University-Student-Experience-and-Recommendation-System)

RAG-based university recommendation system using **10K+ student reviews** collected from multiple public sources. Includes LLM-powered review processing, embeddings, retrieval, source-grounded Q&A, and university comparison.

**Stack:** `Python` `FastAPI` `LangChain` `OpenAI` `ChromaDB` `PostgreSQL` `React`

### 💼 [Job AI CRM — AI Job Application Tracker](https://github.com/zeynepuguz/Job-Application-AI)

AI-powered job application assistant with an **agent pipeline** for job analysis, email generation, and quality review. Includes CV management, company research with RAG, and Gmail/SMTP integration.

**Stack:** `Python` `FastAPI` `LangChain` `OpenAI` `Pinecone` `PostgreSQL`

### 📊 [AI Data Analyst Agent](https://github.com/zeynepuguz/DeepSeek-V3-2-Project)

AI-powered data analysis application that converts natural language questions into analysis plans, executes them with Pandas, and generates charts, metrics, and AI-driven insights.

**Stack:** `Python` `Pandas` `Streamlit` `DeepSeek API` `OpenAI API`

### 📄 [Data Document AI Assistant](https://github.com/zeynepuguz/Data-Document-AI-Assistant)

Document-based RAG assistant for semantic search and question answering over PDF files, with source reporting and guardrails that restrict responses to indexed document content.

**Stack:** `Python` `OpenAI` `File Search` `Vector Store`

### 🧠 [Turkish Sentiment Analysis — Deep Learning NLP](https://github.com/zeynepuguz/Turkish-Sentiment-Analysis-with-Deep-Learning-LSTM-Models-)

Turkish sentiment analysis system using Zemberek-based preprocessing, BERT-based data augmentation, and multiple LSTM architectures. Compared LSTM, Stacked LSTM, CNN-LSTM, and BiLSTM models, reaching **77% validation accuracy and 76.8% Macro F1**.

**Stack:** `Python` `TensorFlow` `PyTorch` `Scikit-learn` `Zemberek` `NLPaug`

### 📈 [InsightHub — Data Analytics & Management Platform](https://github.com/zeynepuguz/InsightHub)

Full-stack platform for employee data and feedback management with REST APIs, authentication, role-based access control, and data filtering.

**Stack:** `Java` `Spring Boot` `React` `PostgreSQL` `Spring Data JPA`
